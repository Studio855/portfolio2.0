# Jae Johnson Portfolio

A minimal, responsive portfolio inspired by the supplied reference image.

## Run locally

No build step is required.

- Open `index.html` directly in a browser, or
- serve the folder with any static server.

## Deploy to GitHub + Vercel

1. Create a new GitHub repository.
2. Upload `index.html` and `style.css`.
3. Import the GitHub repository into Vercel.
4. Framework preset: **Other** (or leave it as detected).
5. Build command: none.
6. Output directory: `.`

The site loads **Inter** from Google Fonts. The project artwork is intentionally represented by six blue numbered placeholders, ready to be replaced with real project images later.
